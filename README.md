## Sobre

Construo backends e APIs em PHP/Laravel com foco em separação de responsabilidades, testabilidade e código que continua barato de manter depois do primeiro release. Meu interesse principal é arquitetura aplicada: DDD, Clean Architecture e microsserviços usados onde resolvem um problema real, não como enfeite.

- **Formação:** Bacharelado em Sistemas de Informação · Pós-graduação Lato Sensu em Engenharia de Software
- **Trabalho hoje com:** APIs REST em Laravel, integrações (WhatsApp, gateways, serviços de terceiros), frontends em Vue/Nuxt e containers com Docker
- **Estudando:** mensageria e comunicação entre serviços, observabilidade e testes de integração
- **Comunidade:** mentoria de desenvolvedores em início de carreira
